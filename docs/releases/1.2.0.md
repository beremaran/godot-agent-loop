# Godot Agent Loop 1.2.0

> This release was prepared but never tagged. The editor-bridge work it
> describes ships in 2.0.0, where the settings-tools routing below
> (modify_project_settings, set_main_scene, manage_input_map) was removed by the
> lean surface reduction.

Godot Agent Loop `1.2.0` routes project.godot mutations through the attached
editor so the editor never prompts to reload the project file from disk.

## Changed

- While an editor session is connected, `modify_project_settings`,
  `set_main_scene`, and `manage_input_map` add/remove are applied through
  `ProjectSettings` inside the editor and persisted with the editor's own save.
  Because the editor writes the file itself, its recorded last-saved time
  tracks the file and the "Files have been modified on disk" reload dialog no
  longer appears for `project.godot` when the editor regains focus.
- The additive `project_settings` editor bridge command decodes each JSON
  entry, preserves the existing setting's Variant type, merges `InputEventKey`
  events into the in-memory input action with physical keycode deduplication,
  and erases a setting when the value is null.
- Without an attached editor, or when the addon predates the command, these
  tools keep the declared file-backed implementation unchanged.

There are no runtime protocol changes. Editor protocol `2` is unchanged; the
persistent editor addon must be updated to `1.2.0` for the new routing (and
Godot restarted once).

## Install

```bash
npx -y @beremaran/godot-agent-loop@1.2.0
```

Users of `1.1.6` should update their pinned agent adapter or MCP command to
`1.2.0`.
