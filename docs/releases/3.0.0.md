# Godot Agent Loop 3.0.0

Godot Agent Loop `3.0.0` removes six redundant tool identities and the
shell-redundant editor/validation/debug identities that 2.0.0 had advertised.
The `core` surface drops from 19 to 16 tools and the full catalog from 61 to 56,
leaving a leaner feedback loop with fewer duplicate paths to the same engine
state.

## BREAKING: advertised core tools removed

- **Six redundant tool identities are gone.** `get_godot_version`,
  `get_project_info`, `validate_scripts`, `game_os_info`, `game_list_signals`,
  and `export_project` are removed from the catalog and return an unknown-tool
  error.
- **`editor_control` mutating actions removed.** `set_property` and
  `rename_node` are removed from `editor_control`; scene mutations go through
  `editor_transaction` so they remain one undo step. `editor_control` keeps
  inspect, select, save, reload, open_scene, undo, and redo.
- **Redundant editor and validation identities removed.** `launch_editor` is
  removed; `editor_session ensure` with `launchIfNeeded` covers attach-or-launch.
  `validate_script` is removed; pass `scriptPaths` to `run_project_tests`-style
  headless checks.
- **`get_debug_output` removed**, superseded by the cursor reads
  `game_get_logs` and `game_get_errors`, which page the same captured process
  output with `remaining`/`byteLimited` bounds.
- **Dead headless-operation scaffolding deleted.**
  `src/headless-operation-runner.ts` and `src/headless-operation-service.ts`
  (plus the `executeOperation` path and the `godot_operations.gd` script they
  drove) are removed; `src/headless-mode.ts` stays as the `run_project`/editor
  headless gating flag.
- **New hidden `game_pause` tool.** Sets or clears `SceneTree.paused` on the
  running game through the existing `pause` runtime command; reachable through
  `godot_catalog` + `godot_call`.

## Migration

Clients of `2.0.0` must switch the removed identities:

- `get_godot_version` / `get_project_info` → `run_project` metadata or
  `analyze_project_integrity`/host file reads.
- `validate_scripts` / `validate_script` → `run_project_tests` with
  `scriptPaths`.
- `get_debug_output` → `game_get_logs` / `game_get_errors`.
- `export_project` → `verify_export_readiness`.
- Signal introspection (`game_list_signals`) → `game_get_node_info` at
  `detail=full`.
- `launch_editor` → `editor_session` ensure with `launchIfNeeded`.

Exact byte/token surface figures live in
[`docs/coverage/tool-surface.json`](../coverage/tool-surface.json).

## Verification

50 unit tests pass on Node 22 (`npm test`; 5 test files, all passing). `npm run
check` (lint, one build, and the retained unit suite) passes cleanly.

The retained MCP-to-Godot E2E suite was **not** run locally for this release; it
runs in CI against Godot 4.7 on tag push. Godot 4.7 remains the compatibility
floor and primary target.

## Install

```bash
npx -y @beremaran/godot-agent-loop@3.0.0
```

Users of `2.0.0` should update their pinned agent adapter or MCP command to
`3.0.0`.
